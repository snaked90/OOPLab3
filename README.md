# OOPLab3 — Satellite Management System

## Опис

Програма реалізує клас `Satellite` з характеристиками (назва, тип, висота
орбіти, дата запуску, потужність передавача, стан активності, рівень
пального, категорія орбіти) та поведінкою (передача даних, перемикання
живлення, зміна висоти орбіти, симуляція природного зниження орбіти).

Порівняно з Lab-2, до класу додано три перевантажені конструктори (без
параметрів, за назвою й типом, повний набір), один з яких викликає інший
через `this(...)`. Метод зміни висоти орбіти `AdjustAltitude` має три
перевантажені версії: звичайну, екстрену (з підвищеною витратою пального)
та за замовчуванням (стандартний підйом на 100 км).

## Функціонал

- Додавання об'єкта: вручну (повний конструктор), тестовий супутник за
  замовчуванням, випадково обраний конструктор (з повідомленням, який саме
  спрацював), з обмеженням кількості N
- Перегляд усіх об'єктів у табличній формі
- Пошук за типом або назвою
- Демонстрація поведінки об'єкта, включно з усіма трьома версіями
  перевантаженого методу `AdjustAltitude`
- Видалення за номером або за типом

## Структура проєкту

- `Program.cs` — точка входу, меню, введення й обробка виключень
- `Satellite.cs` — клас супутника з конструкторами, властивостями та
  перевантаженими методами
- `SType.cs` — enum типів супутників
